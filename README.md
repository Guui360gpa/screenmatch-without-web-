🎬 ScreenMatch

Plataforma de streaming desenvolvida em Java, que consome dados de uma API externa para exibir informações sobre séries e episódios, como título, avaliação e número de temporadas.


O ScreenMatch é um projeto que simula o funcionamento básico de uma plataforma de streaming, permitindo buscar e visualizar dados de séries a partir de uma API.

O sistema realiza:

Consumo de API HTTP
Conversão de JSON para objetos Java
Organização de dados de séries e episódios

🚀 Tecnologias utilizadas

☕ Java 17+

🌐 API HTTP (HttpClient)

🔄 Jackson (para conversão JSON)

📦 Programação orientada a objetos (POO)
